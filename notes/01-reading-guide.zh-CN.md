# 从普通返回映射到统一计数

这份导读只解释问题和证明结构。严格的参数计数论证在 [英文正文](../manuscript/uniformity.pdf)，具体分析难点在 [重新检验性质审查](04-retestability-audit.md)。

## 先把极限环变成零点

在一条周期轨道上取一个很短的横截面，记横截坐标为 $r$。附近轨道走一圈后回到截面，形成返回映射 $\Pi(r)$。周期轨道对应

$$D(r)=\Pi(r)-r=0.$$

孤立零点对应极限环；一整段零点不是一整段极限环。若 $D'(r)\ne0$，这个周期轨道双曲。一般问题还必须容许 $D'(r)=0$ 的孤立零点。

现在让向量场的系数 $p$ 变化。问题不再只是“这个 $D$ 有几个零点”，而是“所有系数的 $D_p$ 是否共享一个有限上界”。参数接近退化位置时，原来好用的横截面、坐标和存在区间都可能变化。这正是一般证明的主要负担。

## 最简单的警示例子

令 $0<p,x<1$，考虑

$$F(p,x)=\sin(x/p).$$

每个固定 $p$ 的零点只有有限个，但 $p\to0$ 时数量无界。在二维 $(p,x)$ 平面中，零集是一些直线段，根本没有孤立点。

所以“原总零集的孤立点有限”几乎没有提供所需信息。必须允许追加方程。例如加上 $x=1/2$ 后，得到无限多个孤立解

$$p=\frac{1}{2\pi k},\qquad k=1,2,\ldots.$$

原稿的强假设恰好排除这种情况：每个由允许操作生成的**固定有限系统**都要有有限个绝对孤立解。这里的“绝对”意味着参数也当作未知量；不是宣称所有生成系统共用同一个数字上界。

## 为什么要数连通分支

原稿把一圈运动拆成多个过渡段，再用方程匹配它们的端点。同一条周期轨道可以通过移动切割点得到连续多组表示，因此这些表示通常不是孤立解。

需要数的是表示空间的连通分支。对于固定的 word、固定参数和一个正规图，原稿证明：两个不同的双曲极限环不能落在同一个连通分支。于是能统一控制分支，就能控制极限环。

抽象计数证明的思路是给每个分支放置一个“标记点”：选择一个在边界和无穷远都趋大的函数，使其在每个分支取得最小值；再用适当的线性扰动使这些最小值非退化。最小值和拉格朗日乘子满足另一组方程。强闭包条件保证，这组方程仍在可以处理的范围内。

这里真正需要论证的不是“每个分支随便选一点”，而是选择点所用的方程系统固定、有限，并且继承完整域条件。

## 一个鞍点为什么已经会出现多种尺度

看线性方程

$$\dot x=x,\qquad \dot y=-\lambda y,\qquad \lambda>0.$$

从 $(r,1)$ 到 $(1,r^\lambda)$ 的飞行时间为 $L=\log(1/r)$，收缩深度为 $W=\lambda L$。即便 $L\to\infty$，$W$ 也可能有界、缓慢发散或与 $L$ 同阶。

这说明，不能只研究固定参数下的一条渐近展开。原稿的 flags 和 packets 用来保留多种尺度之间的关系，以及在复区域、微分和隐函数操作后仍可使用的估计。

“比任意给定阶的指数都小”也不等于恒为零。例如 $e^{-L^2}$ 对每个固定 $A>0$ 都是 $o(e^{-AL})$，却始终为正。要从形式展开全零推出实际函数全零，必须使用额外的复分析假设。这是 separation 部分的职责。

## 术语表

| 原稿术语 | 在本项目中的理解 | 不能偷换成什么 |
| --- | --- | --- |
| parameter fiber | 固定 $p$ 后的解空间 $M_p$ | 所有坐标一起变化的总零集 |
| absolute isolated zero | 所有保留坐标一起作为未知量时的孤立解 | 每个参数纤维里的孤立点 |
| finite differential and algebraic closure | 有限次加坐标、微分、代数运算、合法求逆等生成的系统 | 只有原方程，或所有解析函数 |
| positive-margin completeness | 坐标有界且所有列出的开域余量远离零时，极限仍在合法解析域 | 在余量趋零的边界也解析延拓 |
| proper barrier | 子水平集紧的障碍函数，保证每个分支取得最小值 | 仅仅有下界的函数 |
| regular graph | 辅助变量由可逆 Jacobian 局部唯一确定 | 任意加入的自由辅助变量 |
| independent-coordinate derivative | 先把核的参数作为独立变量求偏导 | 先代入图关系再对约束曲线求导 |
| flag | 有限组有序尺度和保留的精确对数关系 | 对整个参数空间统一选好的坐标系 |
| packet | 实际函数、展开及复区域和余项估计的组合 | 只有形式级数 |
| separation | 第一非零项控制函数，或形式全零导致实际全零 | 只靠实轴上的任意阶小量估计 |
| retestability | 合法改变自由输入后，所需终端普通解析系数芽保持相同 | 沿原序列数值趋零 |
| terminal coefficient germ | 有限普通变量附近的解析函数芽 | 只在一个点的取值 |
| positive（在 packet/消去语境中） | 两套形式展开没有负字典序指数的非零项 | 函数在实数意义下处处大于零 |
| old free input | 在消去或图增广之前已有、可从原坐标恢复的自由输入 | 新加且对原解没有影响的辅助自由度 |
| word | 固定有限字母表中的一串几何过渡类型 | 为某条坏序列临时选出的任意长分割 |

## 怎样读才不被长证明淹没

读每个引理时写下三个问题：输入的具体变量有哪些？输出的常数依赖什么？下一步用到的是原值、独立偏导还是约束后的导数？

然后特别检查三个量词：是否先固定系统再取序列；是否先固定精度损失的指数再提高展开精度；是否只需对可数个见证参数选共同扰动，而非对不可数个参数作交集。

这不是把困难分析删掉，而是把困难精确定位到少数可讨论的陈述。当前项目最重要的未完成工作见 [审查任务](04-retestability-audit.md)。
