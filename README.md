# Hilbert 16: a proof audit and reconstruction

A public research project to make OpenAI’s proposed uniform bound for planar polynomial limit cycles easier for specialists to understand and independently check.

The initial research edition is being reviewed through [the project’s pull requests](https://github.com/h-lu/hilbert16-proof-audit/pulls). It includes an English mathematical manuscript, Chinese reading guides, a dependency ledger, and pinned source references.

The project distinguishes reconstructed conditional arguments from unverified analytic inputs. It does not claim complete independent verification or formal certification of the general Hilbert bound.
