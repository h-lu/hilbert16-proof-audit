# Hilbert 第十六问题第二部分：证明重构与公开审查

[English](README.md) · [英文证明 PDF](manuscript/uniformity.pdf) · [完整依赖图](notes/00-proof-map.md)

本项目研究 OpenAI 提出的平面多项式向量场极限环统一上界证明。目标是让领域数学家能用通常的数学阅读方式检查：先看准确命题和量词，再看独立证明，最后核对上游是否真正满足每项假设。

**目前完成的是第一批可审阅材料，尚未完成一般上界的独立认证。** 参数统一界这个抽象环节已经重写为自包含的条件性证明。困难仍在上游：实际过渡映射及其全部所需微分、代数增广，是否具备该定理要求的绝对孤立零点有限性。

## 建议阅读顺序

1. [入门与术语表](notes/01-reading-guide.zh-CN.md)：区分逐个有限、参数统一有限和绝对有限，理解参数为何要暂时当作未知量。
2. [统一界证明中文导读](notes/02-uniformity-guide.zh-CN.md)，然后读 [英文完整证明](manuscript/uniformity.pdf)。证明将每个连通分支变成一个非退化极小点，再对参数维数归纳。
3. [闭包接口清单](notes/03-closure-contracts.md)：逐项检查图增广、独立偏导、分母、域边界和新增乘子。
4. [重新检验性质审查](notes/04-retestability-audit.md)：下一步最值得投入的分析部分，每项任务都写明“要证明什么才算通过”。
5. [旋转与空间缩放](notes/05-geometric-reductions.md)：为什么退化极限环和逃向无穷的位置不需要额外假定。

## 核心区分

| 表述 | 是否足够推出统一界？ |
| --- | --- |
| 每个固定向量场只有有限个极限环 | 不足够 |
| 原方程总零集只有有限个孤立点 | 不足够；总零集可能由曲线组成 |
| 每个固定有限增广系统，在所有坐标都作为未知量时只有有限个孤立解 | 加上完整域条件和满秩条件，足够 |
| 实际匹配系统满足上述强条件 | 原稿的核心证明负担；本仓库仍在审查 |

完整证明给出两个反例，分别说明：为什么不能删去“整个闭包”，以及为什么必须记录所有可能逃离的开域边界。证明检查不依赖数值实验。

核对记录与原始链接见 [社区资料审查](notes/06-community-sources.md)。本项目将原稿固定在一个 Git commit，并记录下载文件的哈希，避免不同版本之间的命题、行号混用。

## 参与方式

最有帮助的反馈不是笼统说“证明太复杂”或“看起来正确”，而是给出一个具体的输入—输出接口：某个引理交付了什么，下一步实际需要什么，两者是否一致。可按 [贡献说明](CONTRIBUTING.md) 提交 issue 或修改建议。

所有“已重构”结论都保留其条件。初稿使用 AI 撰写和交叉审查；尚无记录的独立人工审定，也未把一般上界形式化为 Lean 证明。
